# Redemoinho

| **Redemoinho** |
| :--- |
| **ID:** 621 |
| **Categoria/Tipo:** Alquimia / Vento |
| **Foco/Requisitos:** (Foco: 61-80) (Foco) |

## Ativação & Efeitos
| Elemento | Valor / Regra |
| :--- | :--- |
| **Tempo** | 1d3 |

## Descrição
Ao atirar a poção em um determinado lugar, é formada uma área de porte médio que cria uma parede de vento que protege tudo que estiverem no centro dessa área de ataques físicos, além de lhe dar um aumento temporário de 1d3 na força e resistência.
