# Tiro cadente

| **Tiro cadente** |
| :--- |
| **ID:** 609 |
| **Categoria/Tipo:** Vento / Arco |
| **Foco/Requisitos:** (Foco: 61-80) (Foco) |

## Descrição
Caso acerte um ataque a longo alcance usando um arco, permite apanhar outra flecha atirar em seguida, mas ataca com uma penalidade equivalente a quantidade de flechas disparadas com essa habilidade.
