# Filhos das Sombras

| **Filhos das Sombras** |
| :--- |
| **ID:** 520 |
| **Categoria/Tipo:** Escuridão |

## Descrição
Cria criaturas de escuridão que tomam o formato desejado pelo usuário. Essas criaturas agarram o oponente dificultando-o ou até mesmo impedindo-o de se mexer ou se concentrar, consequentemente suas ações serão impedidas ou dificultadas para se realizarem.
