# Escuridão dilacerante

| **Escuridão dilacerante** |
| :--- |
| **ID:** 516 |
| **Categoria/Tipo:** Escuridão |
| **Foco/Requisitos:** (Foco: 61-80) (Foco) |

## Ativação & Efeitos
| Elemento | Valor / Regra |
| :--- | :--- |
| **Ativa** | 1d20 |
| **Dano** | 4d5+1d8 |

## Descrição
Acerta um ataque inicial nos olhos que pode ou não ser bem sucedido, se cegar o alvo o dilacera de todas as direções possíveis deixando seu corpo retalhado, caso não, apenas irá realizar diversos cortes com muita agilidade.
