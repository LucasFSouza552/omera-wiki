# Luz Suprema

| **Luz Suprema** |
| :--- |
| **ID:** 624 |
| **Categoria/Tipo:** Luz / Arcano |
| **Foco/Requisitos:** (Foco: 81-100) (Foco) |

## Ativação & Efeitos
| Elemento | Valor / Regra |
| :--- | :--- |
| **Ativa** | 1d20 |
| **Dano** | 1d10+((ROUND(75/10))*2) |
| **Desvantagem** | 1 Rodada de cegueira |

## Descrição
Ele se torna tão brilhante quanto uma estrela podendo cegar aqueles que olharem para ele a olho nu (e causando queimaduras com contato físico) a habilidade lhe confere a capacidade de usar Hiper-Aceleração sem preocupações de causar dano ao próprio corpo suas flechas se tornam capazes de hiper-acelerar e ficar invisíveis (sendo que ele só pode usar uma dessas habilidades nas flechas). As flechas ganham uma propriedade de dano em área a sua escolha (explosão de luz, Cegueira momentânea apenas na explosão).
