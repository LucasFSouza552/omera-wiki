# Arremesso das Trevas

| **Arremesso das Trevas** |
| :--- |
| **ID:** 515 |
| **Categoria/Tipo:** Escuridão |
| **Foco/Requisitos:** (Foco: 41-60) (Foco) |

## Ativação & Efeitos
| Elemento | Valor / Regra |
| :--- | :--- |
| **Ativa** | 1d20 |
| **Dano** | 1d8+1d4 |

## Descrição
Arremessa uma de suas adagas, caso o arremesso seja certeiro irá acertar o alvo em algum dos 4 membros podendo deixá-la presa e debilitada temporariamente, caso não seja certeiro dará dano parcial, mas será usado para realizar um ataque surpresa em seguida.
