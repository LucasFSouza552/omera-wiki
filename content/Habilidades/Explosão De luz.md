# Explosão De luz

| **Explosão De luz** |
| :--- |
| **ID:** 623 |
| **Categoria/Tipo:** Luz / Arcano |
| **Foco/Requisitos:** (Foco: 61-80) (Foco) |

## Ativação & Efeitos
| Elemento | Valor / Regra |
| :--- | :--- |
| **Dano** | 1d10+(ROUND(75/10)*2) |

## Descrição
É capaz de gerar explosões de luz primeiramente seu corpo se torna tão brilhante quanto uma estrela (o que já é capaz de cegar quem olhar para o mesmo), após isso, uma explosão de luz acontece cegando e causando danos em todos á volta. Podendo aplicar os efeitos descritos anteriormente no arco e atirando em forma de flecha.
